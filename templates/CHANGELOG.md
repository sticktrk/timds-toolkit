# Design System Changelog

Every release of this system, newest first, written for the people who use
it. Add a note under `## Unreleased` with each change: what changed and where
to see it, in one or two sentences. Lead with the area it touches, so the note
reads "Brand · Color: ..." or "Print DS: ..."; use "Maintenance:" for toolkit
upgrades and plumbing. Merging rolls the notes into the next version, and the
published system shows this file at `/changelog/`.

A version is the UTC day it was released and its number that day:
`2026.10.12-1`, then `2026.10.12-2` for a second release the same day.
